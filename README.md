# Painel de Gestão de Recursos — KW Brasil

Painel web (HTML/JS estático) do inventário de equipamentos: mapa, PEX × cadastrado e atualizações por coordenador.

- Os dados ficam no Supabase, atrás de login por e-mail corporativo (@kwbrasil.com.br). Sem login, o painel não mostra nada.
- Este repositório contém só o código do painel; não há dados de inventário, PEX nem fotos.
- Publicado por GitHub Pages (pasta `painel/`).
